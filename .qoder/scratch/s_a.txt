### lite_llama/distributed/parallel_state.py | total=360 | doc=28L/1683c | usage=True
DOC| Parallel process groups: the rank grid that TP and DP agree on.
DOC| 
DOC| Ranks form a ``dp_size x tp_size`` grid laid out so that one replica's TP ranks are
DOC| contiguous — ``global_rank = dp_rank * tp_size + tp_rank`` — which is what lets the two
DOC| kinds of parallelism stay unaware of each other. **TP** splits every weight matrix
DOC| across the ranks of one replica, so layers that split their input finish with an
DOC| all-reduce (:func:`all_reduce_tp`) over *that replica's* group only. **DP** replicates
DOC| the whole model per group and shards the *requests* instead, so it needs no collective
DOC| in the forward at all; ``torch.distributed`` is therefore only initialised when
DOC| ``tp_size > 1``, and pure DP runs on plain multiprocessing queues
DOC| (:mod:`lite_llama.engine.data_parallel`).

DOC| without the plumbing being threaded through its constructor, exactly as vLLM's
DOC| ``parallel_state`` does. The default state is a world of one, where every collective is
DOC| a no-op and every layer is full width — so single-GPU code paths never branch.
