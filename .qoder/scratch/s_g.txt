DOC| CUDA Graph regression tests.
DOC| 
DOC| A captured graph replays a fixed sequence of kernels against fixed memory
DOC| addresses. That makes two failure modes possible that eager execution simply
DOC| cannot have:
DOC| 
DOC| * **Stale pointers.** If capture bakes in a tensor that is later reallocated,
DOC|   replay reads whatever now occupies that address. The symptom is output that is
DOC|   plausible-looking but wrong, and *different* on each call.
DOC| * **Out-of-bounds capture.** Capturing a batch size larger than the request
DOC|   table indexes past ``b_req_tokens_table``, corrupting the CUDA context with
DOC|   delayed CUBLAS errors far from the real cause.
DOC| 
DOC| Every test therefore pins graph output against eager output on the same
DOC| checkpoint: eager is the oracle, and byte-identical greedy text is the contract.
