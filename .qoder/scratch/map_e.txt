@@@FILE lite_llama/observe/metrics.py
"""Request-level metrics: a tiny in-process registry with a Prometheus rendering.

:class:`Counter` / :class:`Gauge` / :class:`Histogram` are the primitives
and :class:`EngineMetrics` wires them to the request lifecycle; every
``render`` emits Prometheus text format with no server dependency.

Usage:
    metrics = EngineMetrics.from_env()
    print(metrics.render_prometheus())
"""
@@@END
@@@FILE lite_llama/observe/trace.py
"""Optional OTLP tracing: one span per request, exported over OTLP/HTTP.

:class:`Tracer` wraps an OpenTelemetry tracer when the endpoint is
configured via :meth:`Tracer.from_env`; unconfigured, ``start_span``
returns None and every call is a cheap no-op.

Usage:
    tracer = Tracer.from_env()
    span = tracer.start_span("generate")
"""

@@@FILE lite_llama/platform/spec.py

@@@FILE lite_llama/tools/harness/reference.py
"""The same layer as HuggingFace builds it, for the harness to diff against.

:class:`HFLayerReference` instantiates the checkpoint's own decoder layer

@@@FILE lite_llama/tools/harness/single_layer.py
"""One decoder layer, built and run on its own.

:class:`SingleLayerHarness` builds just layer ``i`` of a checkpoint,
runs prefill and decode steps on it, times the dispatched kernels, and

without loading the whole model.

Usage:

@@@FILE lite_llama/tools/observability/collective_stats.py
"""Collective accounting: what tensor parallelism actually puts on the wire.

``CollectiveStats.collect()`` opens a window that tallies bytes per
collective op; the window's report ranks ops by traffic, so sharding
decisions get numbers instead of guesses.

Usage:
    with CollectiveStats.collect() as stats:
        all_reduce_tp(x)
    print(stats.report())
"""
@@@END
@@@FILE lite_llama/tools/profiling/memory.py

Usage:

@@@FILE lite_llama/tools/profiling/structure.py
